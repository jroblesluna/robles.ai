# Tu chatbot en 60 segundos

ID: `sitechatbot` · Estado de la demo: `live`.

![Fotograma inicial](first-frame.jpg)

1. Carga `first-frame.jpg` como First frame en Firefly, con salida 16:9 a 720p.
2. Copia el contenido completo de [firefly-prompt.txt](firefly-prompt.txt).
3. Genera cinco segundos con cámara fija y sin audio.
4. Descarga el original como `sitechatbot-firefly-master.mp4`.
5. Revisa anatomía/geometría, estabilidad, ausencia de textos y zona central antes de comprimir. Consulta el README general para exportación y carga a demanda.

La foto ya fue generada con image_gen en la fase anterior. Esta entrega la reutiliza y prepara; no es una generación nueva ni un clip de video terminado.
