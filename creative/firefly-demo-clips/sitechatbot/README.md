# Your chatbot in 60 seconds — v2

Use **first-frame-v2.jpg** in Firefly → Frames → First, paste **firefly-prompt-v2.txt**, keep Last empty. Generate 16:9, 720p, eight seconds, 24 fps, Audio off. Preserve the full composition.

Every explanatory label, connector, tracking graphic and output belongs inside the video. The first frame already contains the completed concept; animation demonstrates its relationships.

## Review the actual video

- Question, source and answer are all visible in the final video.
- The cited SERVICES chip corresponds to the SERVICES source being activated.
- No random changing text, unrelated reply, opaque background-only motion or outside overlay needed.
- Reject scrambled text, cropped graphics, detached tracking or a concept that needs a website layer to make sense.

Save the original as **sitechatbot-firefly-v2-master.mp4**. Use the v2 encoder to retain all eight seconds in 16:9. Videos have not been generated or temporally validated yet. Files without v2 in this folder are superseded v1 material.
