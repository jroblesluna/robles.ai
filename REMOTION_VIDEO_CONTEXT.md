## 8. Concepto creativo

### 8.1 Idea rectora: **"El Plano Antes del Edificio"**

La IA fracasa cuando se construye sin plano. El video es la **traducción visual de un plano
arquitectónico que se dibuja solo**: líneas azules que se trazan sobre fondo navy profundo,
nodos que se conectan, un caos inicial de datos dispersos que se **ordena en una grilla**, y
esa grilla se convierte en el roadmap por etapas.

**Metáfora visual central:** *desorden → grilla → ruta → resultado.*

### 8.2 Lenguaje visual

- **Base:** fondo navy `#0F172A → #1E3A8A → #172554` en degradado diagonal animado (es
  literalmente el `animated-bg` del sitio — coherencia de marca inmediata).
- **Trazo:** líneas finas azules (`rgba(59,130,246,0.5)`), grilla técnica de 50px, círculos
  concéntricos — tomados del SVG del Hero real del sitio.
- **Partículas:** puntos blancos 2px, densidad baja, deriva lenta. **Sutiles.** No confeti.
- **Profundidad:** capas con parallax leve (fondo 0.2× / medio 0.6× / frente 1×).
- **Glassmorphism medido:** tarjetas `rgba(255,255,255,0.06)` + `blur(20px)` + borde
  `rgba(255,255,255,0.12)`. Nada de sombras exageradas.
- **Luz:** un *glow* radial azul que sigue el foco de atención de la escena.

### 8.3 Lo que este video NO es

❌ Robots humanoides genéricos · ❌ cerebros con circuitos · ❌ "matrix" de números verdes
❌ stock footage de gente en reuniones señalando pantallas · ❌ música épica de tráiler
❌ más de 7 palabras por pantalla · ❌ animaciones con rebote juguetón (bounce)

## 9. Guion escena por escena (máster 60 s · 30 fps · 1800 frames)

> Convención: `[f inicio – f fin]`. Transiciones = crossfade/slide de **15 frames**
> superpuestos entre escenas (usar `TransitionSeries` de `@remotion/transitions`).

### ESCENA 1 — HOOK `[0 – 150]` (0–5 s)

- **Visual:** negro → aparece un único punto de luz azul en el centro. Se expande en una
  grilla técnica que cubre la pantalla. Números y fragmentos de datos flotan desordenados.
- **On-screen (secuencial, una idea por vez):**
  - f20–f80: `83% de las empresas ya se declara lista para la IA.`
  - f85–f150: `Casi ninguna sabe por dónde empezar.` *(entra cuando la primera línea baja a 40% de opacidad)*
- **VO:** *"El ochenta y tres por ciento de las empresas ya se declara lista para adoptar inteligencia artificial."*
- **Nota:** el `83%` es un contador animado 0→83 en 25 frames con easing expo-out.
- **Micro-rótulo legal** (esquina inferior, 11px, opacidad 45%): `Dato de industria.`

### ESCENA 2 — EL PROBLEMA `[150 – 360]` (5–12 s)

- **Visual:** ~14 chips flotando en desorden con buzzwords (`LLM`, `RAG`, `Copilot`,
  `Agentes`, `Fine-tuning`, `Vector DB`, `MLOps`, `OCR`, `Chatbot`, `Automatización`…).
  Rotaciones leves, colisión suave, sensación de ruido. En **f300** una línea azul barre la
  pantalla y **todos los chips se alinean de golpe en una grilla ordenada 4×3**.
- **On-screen:** f170–f290 `El problema no es la tecnología.` → f300–f360 `Es empezar sin diagnóstico.`
- **VO:** *"Pero la mayoría no falla por falta de tecnología. Falla por empezar sin un diagnóstico."*
- **Este es el beat más importante del video.** El "snap" de f300 debe sentirse satisfactorio:
  todos los chips llegan a su posición con un spring de damping alto (sin rebote) y un flash
  azul de 6 frames.

### ESCENA 3 — REVELACIÓN DE MARCA `[360 – 510]` (12–17 s)

- **Visual:** la grilla se contrae hacia el centro y se convierte en el **logo de Robles.AI**.
  Logo en blanco sobre navy, con un barrido de luz (shine) diagonal de izquierda a derecha.
- **On-screen:**
  - Logo (f370–f430, escala 0.85→1 con spring)
  - f430–f510: `Soluciones Robustas de Inteligencia Artificial`
  - f450–f510 (sub, opacidad 70%): `Cupertino, CA · LatAm ⇄ USA · desde 2011`
- **VO:** *"Robles punto A-I. Soluciones robustas de inteligencia artificial."*
- **Audio:** golpe grave (impact/sub-bass) en f370.

### ESCENA 4 — EL MÉTODO `[510 – 990]` (17–33 s) ← **núcleo del video**

Cuatro sub-beats de 120 frames. Una **línea de ruta horizontal** cruza la pantalla y en cada
sub-beat avanza un tramo, dejando un nodo encendido atrás. Los pasos ya vistos quedan
visibles a opacidad 35% — al final del beat **los 4 se ven simultáneamente**: eso es el roadmap.

| Sub-beat | Frames | Número | Título | Línea de apoyo en pantalla |
|----------|--------|--------|--------|----------------------------|
| 4.1 | 510–630 | `01` | **Diagnóstico** | Procesos y datos reales, no solo lo documentado. |
| 4.2 | 630–750 | `02` | **Priorización** | Por impacto, factibilidad y dependencia de datos. |

### 11.4 Sistema de animación — reglas obligatorias

```ts
// hooks/useEntrance.ts
import { interpolate, spring, useCurrentFrame, useVideoConfig, Easing } from 'remotion';

/** Entrada estándar: opacidad + desplazamiento + escala, sin rebote. */
export const useEntrance = (startFrame: number, opts?: { distance?: number }) => {
  const frame = useCurrentFrame();
  const { fps } = useVideoConfig();
  const local = frame - startFrame;

  const progress = spring({
    frame: local,
    fps,
    config: { damping: 200, stiffness: 100, mass: 0.6 }, // crítico: damping alto = cero bounce
  });

  const distance = opts?.distance ?? 32;
  return {
    opacity: interpolate(local, [0, 12], [0, 1], { extrapolateLeft: 'clamp', extrapolateRight: 'clamp' }),
    transform: `translateY(${interpolate(progress, [0, 1], [distance, 0])}px) scale(${interpolate(progress, [0, 1], [0.96, 1])})`,
  };
};

/** Curva de marca para movimientos no-spring (barridos, cámara, contadores). */
export const BRAND_EASE = Easing.bezier(0.16, 1, 0.3, 1); // expo-out
```

**Reglas no negociables:**

1. **Todo `interpolate` lleva `extrapolateLeft: 'clamp'` y `extrapolateRight: 'clamp'`.**
   Sin esto, los valores se disparan fuera del rango y aparecen glitches.
2. **`damping: 200`** en los springs. Este video es corporativo: nada rebota.
3. **Salidas más rápidas que entradas** (entrada ~12–18f, salida ~8–10f).
4. **Stagger de 5–8 frames** entre elementos hermanos. Más lento se siente pesado.
5. Cada escena vive dentro de `<Sequence from={X} durationInFrames={Y}>`, y **dentro de la
   escena `useCurrentFrame()` ya devuelve el frame local** (empieza en 0). No restes offsets
   manualmente dentro de una Sequence.
6. Transiciones entre escenas con `TransitionSeries` + `linearTiming({durationInFrames: 15})`
   y presentación `fade()` o `slide({direction:'from-right'})`. Máximo 2 tipos distintos en
   todo el video.
7. **Blur solo en entradas de texto grande** (`blur(8px)` → `blur(0)` en 10 frames). Es caro
   de renderizar; no lo apliques a capas de pantalla completa.

### 11.5 Aleatoriedad determinista (crítico)

`Math.random()` **rompe el render** (cada frame se renderiza en un worker distinto y las
partículas saltarían). Usa siempre el `random()` de Remotion con semilla:

```tsx
import { random } from 'remotion';

const particles = new Array(60).fill(0).map((_, i) => ({
  x: random(`px-${i}`) * 1920,
  y: random(`py-${i}`) * 1080,
  speed: 0.3 + random(`ps-${i}`) * 0.7,
  size: 1 + random(`sz-${i}`) * 2,
}));
```

### 11.6 Performance del render

- Partículas: **máximo 60** en 16:9. Usa `<div>` con `transform`, no canvas.
- No animar `box-shadow` ni `filter: blur` en elementos de pantalla completa por frame.
- `will-change: transform, opacity` en los elementos animados.
- Imágenes: usar `staticFile()` + `<Img>` de Remotion (nunca `<img>` nativo — Remotion espera
  la carga antes de capturar el frame).
- Fuente: `@remotion/google-fonts/Inter` con `waitForFonts()`, no `<link>` de Google Fonts.

### 11.7 Comando de render

```bash
npx remotion render RoblesAI-Master-16x9 out/robles-ai-60s.mp4 \
  --codec=h264 --crf=16 --concurrency=4
```
