# Requirements Document

## Introduction

This feature replaces the single abstract cover image in the "El Dominical IA" weekly report with a LinkedIn carousel of slides — one per selected news article — plus a cover slide and a CTA slide. Each slide composites an AI-generated background image with the Robles.AI logo, article title, and a provocative engagement phrase. The carousel is exportable as a PDF (LinkedIn carousel format) or as individual PNG images.

## Glossary

- **Carousel_Generator**: The backend service responsible for orchestrating slide generation, image composition, and PDF export for a dominical report's carousel.
- **Slide_Compositor**: The component that uses the `sharp` library to overlay text and logo onto an AI-generated background image, producing a final slide image.
- **Carousel**: An ordered collection of slides (cover + article slides + CTA slide) representing a LinkedIn carousel post.
- **Cover_Slide**: The first slide of the carousel, introducing the weekly edition with branding and a summary headline.
- **Article_Slide**: A slide corresponding to one selected news article, containing the AI background, logo, title, and engagement phrase.
- **CTA_Slide**: The last slide of the carousel, containing a call-to-action (e.g., follow, subscribe, read more).
- **Engagement_Phrase**: A provocative question or impact statement generated by GPT-4o to entice readers to interact with the post.
- **Admin_Panel**: The web-based administration interface at `/admin/dominical/:id` used to manage dominical reports.
- **Report**: A dominical report record stored in the `dominical_reports` database table, containing selected news, post text, and associated media.

## Requirements

### Requirement 1: Generate Engagement Phrases

**User Story:** As an admin, I want the system to generate a provocative engagement phrase for each selected news article, so that the carousel slides attract reader attention.

#### Acceptance Criteria

1. WHEN a carousel generation is requested, THE Carousel_Generator SHALL call GPT-4o to produce one Engagement_Phrase per selected news article based on the article title, excerpt, and categories.
2. THE Carousel_Generator SHALL return each Engagement_Phrase as a string of 80 characters or fewer.
3. THE Carousel_Generator SHALL generate Engagement_Phrases in Spanish suitable for a Latin American professional audience on LinkedIn.
4. IF GPT-4o returns an error or empty response, THEN THE Carousel_Generator SHALL retry the request once and, upon second failure, return a descriptive error message to the Admin_Panel.

### Requirement 2: Generate AI Background Images

**User Story:** As an admin, I want an AI-generated background image specific to each article's topic, so that each carousel slide is visually relevant and compelling.

#### Acceptance Criteria

1. WHEN carousel generation is requested, THE Carousel_Generator SHALL call the gpt-image-1 model to produce one background image per selected news article using a prompt derived from the article title and categories.
2. THE Carousel_Generator SHALL request images at 1080x1080 pixel dimensions suitable for LinkedIn carousel slides.
3. THE Carousel_Generator SHALL save each generated background image as a PNG file in the server filesystem under a path associated with the report ID.
4. IF the image generation API returns an error, THEN THE Carousel_Generator SHALL log the error and return a failure status for that specific slide without blocking generation of remaining slides.

### Requirement 3: Compose Slide Images

**User Story:** As an admin, I want each slide to combine the background image with the Robles.AI logo, article title, and engagement phrase, so that slides are branded and informative.

#### Acceptance Criteria

1. WHEN a background image is available for an article, THE Slide_Compositor SHALL overlay the Robles.AI logo from `/public/images/logo.png` in a consistent position on the slide.
2. THE Slide_Compositor SHALL render the article title as text on the slide using a legible font size and color that contrasts with the background.
3. THE Slide_Compositor SHALL render the Engagement_Phrase as text on the slide, visually distinct from the title.
4. THE Slide_Compositor SHALL apply a semi-transparent dark gradient or overlay behind text areas to ensure readability regardless of background content.
5. THE Slide_Compositor SHALL produce a final composite image at 1080x1080 pixels in PNG format.

### Requirement 4: Generate Cover Slide

**User Story:** As an admin, I want the carousel to start with a branded cover slide, so that the post has a professional first impression in the LinkedIn feed.

#### Acceptance Criteria

1. WHEN carousel generation is requested, THE Carousel_Generator SHALL produce a Cover_Slide as the first slide of the Carousel.
2. THE Cover_Slide SHALL contain the Robles.AI logo, the text "El Dominical IA", and the week date range from the Report.
3. THE Cover_Slide SHALL use an AI-generated or pre-designed abstract background at 1080x1080 pixels.

### Requirement 5: Generate CTA Slide

**User Story:** As an admin, I want the carousel to end with a call-to-action slide, so that readers are encouraged to follow or engage further.

#### Acceptance Criteria

1. WHEN carousel generation is requested, THE Carousel_Generator SHALL produce a CTA_Slide as the last slide of the Carousel.
2. THE CTA_Slide SHALL contain the Robles.AI logo and a call-to-action message (e.g., "Síguenos para más insights de IA" or "Lee los artículos completos en robles.ai").
3. THE CTA_Slide SHALL be 1080x1080 pixels in PNG format.

### Requirement 6: Export Carousel as PDF

**User Story:** As an admin, I want to export the carousel as a single PDF file, so that I can upload it directly as a LinkedIn carousel post.

#### Acceptance Criteria

1. WHEN the admin requests PDF export, THE Carousel_Generator SHALL combine all slides (Cover_Slide, Article_Slides, CTA_Slide) into a single PDF document with one slide per page.
2. THE Carousel_Generator SHALL produce each PDF page at 1080x1080 pixels.
3. THE Carousel_Generator SHALL return the PDF as a downloadable file via an HTTP endpoint.
4. IF any slide image is missing or corrupted, THEN THE Carousel_Generator SHALL exclude that slide from the PDF and include a warning in the response.

### Requirement 7: Export Individual Slide Images

**User Story:** As an admin, I want to download individual slide images, so that I can use them separately on other platforms if needed.

#### Acceptance Criteria

1. WHEN the admin requests individual image export, THE Carousel_Generator SHALL return the specified slide as a downloadable PNG file via an HTTP endpoint.
2. THE Carousel_Generator SHALL serve each slide image at 1080x1080 pixels in PNG format.

### Requirement 8: Preview Carousel in Admin Panel

**User Story:** As an admin, I want to preview the generated carousel in the admin panel, so that I can review slides before publishing.

#### Acceptance Criteria

1. WHEN a carousel has been generated for a Report, THE Admin_Panel SHALL display a horizontal scrollable preview showing all slides in order.
2. THE Admin_Panel SHALL display each slide as a thumbnail with an option to view full size.
3. THE Admin_Panel SHALL indicate the generation status of each slide (pending, generated, failed).

### Requirement 9: Regenerate Individual Slides

**User Story:** As an admin, I want to regenerate a specific slide without regenerating the entire carousel, so that I can fix individual slides that are unsatisfactory.

#### Acceptance Criteria

1. WHEN the admin requests regeneration of a specific Article_Slide, THE Carousel_Generator SHALL generate a new background image and re-compose that slide without affecting other slides.
2. WHEN the admin requests regeneration of the Cover_Slide or CTA_Slide, THE Carousel_Generator SHALL regenerate only that specific slide.
3. THE Admin_Panel SHALL update the preview to reflect the newly regenerated slide.

### Requirement 10: Edit Slide Text Before Compositing

**User Story:** As an admin, I want to edit the title and engagement phrase on a slide before final composition, so that I can refine the messaging.

#### Acceptance Criteria

1. THE Admin_Panel SHALL display editable text fields for the article title and Engagement_Phrase for each Article_Slide.
2. WHEN the admin modifies slide text and confirms, THE Slide_Compositor SHALL re-compose the slide image with the updated text.
3. THE Admin_Panel SHALL preserve the existing background image when only text is changed.

### Requirement 11: Store Carousel Data

**User Story:** As an admin, I want carousel data persisted in the database, so that generated slides survive server restarts and can be revisited.

#### Acceptance Criteria

1. WHEN slides are generated, THE Carousel_Generator SHALL store slide metadata (file paths, article slug, title text, engagement phrase, generation status) in the database associated with the Report ID.
2. THE Carousel_Generator SHALL store the ordered position of each slide within the Carousel.
3. WHEN the admin loads a Report in the Admin_Panel, THE Admin_Panel SHALL retrieve and display previously generated carousel data from the database.
